# Angular

{% hint style="warning" %}
The Angular API is still subject to change
{% endhint %}

The example setup is live here: [https://example-angular.oidc-spa.dev](https://example-angular.oidc-spa.dev/)

Run it locally with:

```bash
npx degit https://github.com/keycloakify/oidc-spa/examples/angular oidc-spa-angular
cd oidc-spa-angular
npm install
npm run start
```
